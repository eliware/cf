Frequently asked questions

What are scopes?

Scopes are permissions granted to cf by Cloudflare. Each scope controls a capability, such as reading zones or changing DNS records. Choose only the permissions you expect to use.

What do the modules do?

Modules group the scopes used by built-in cf commands. Enabling a module selects its required permissions; shared permissions stay selected while another enabled module still needs them.

How do I use custom scopes with cf api?

Expand the full scope list and select the permissions for the Cloudflare endpoints you plan to call with cf api. The raw API command can reach endpoints beyond the built-in modules, so its required scopes depend on the endpoint and HTTP method you use.

Can I add permissions later?

Yes. Run cf auth login again, select the additional permissions, and authorize the updated profile. Existing credentials are replaced with the new authorization.
